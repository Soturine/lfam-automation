# Código de Conduta

Queremos um espaço respeitoso para aprender e construir juntos.

**Esperamos:** educação e empatia; críticas ao trabalho, nunca às pessoas; aceitar feedback com abertura; reconhecer erros e o crédito de quem ajudou.

**Não toleramos:** assédio, discriminação, ataques pessoais, divulgação de dados pessoais de terceiros ou de credenciais.

**Moderação:** quem mantém o repositório pode editar, ocultar ou remover comentários, issues e PRs que violem estas regras. Para denunciar, use [Reportar uma vulnerabilidade](../../security/advisories/new) (canal privado) ou contate quem mantém o repositório pelo perfil no GitHub.

Adaptado do [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
